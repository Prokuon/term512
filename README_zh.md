# TERM512: 为 AREA512 固件定制的 CardputerAdv 扩展套件

TERM512 是为 [AREA512](https://github.com/engneer-hamachan/area512) 固件定制的 CardputerAdv 扩展套件. 它旨在将 CardputerAdv 重塑为一台契合 AREA512 视觉美学的 Cyberdeck, 成为该固件的专属实体硬件载体

当然, 该套件本质上是一套经过深度风格化设计的 CapTFT 扩展模块, 同样欢迎其他固件的适配

该套件由以下几部分组成:

- 定制设计的 CapTFT: 基于 [CapTFT V2](https://github.com/Prokuon/CardputerADV_Cap_TFT_V2) 重新设计了 A 面, 并将屏幕的最大开合角度由 120° 增加到了 135°;
- 保护底座: 利用 CardputerAdv 底部的两个乐高兼容孔固定, 集成了两个锁扣, 用于在闭合时锁定屏幕盖板, 此外还包含一个挂绳孔;
- 可调阻尼支架: 安装在底部的另外两个乐高兼容孔上, 支持多角度悬停, 并可通过螺栓调节转动阻尼

## 组装说明

将降压电源模块粘贴到屏幕背面, 并按图示使用细导线连接屏幕与排针, 建议使用外径为 0.65mm 的线缆, 接线定义参考表格

![](assets/20260904195042.jpg)

黑色 PCB 屏幕的引脚比蓝色 PCB 屏幕少了 BLK, 其余引脚定义与顺序和蓝色 PCB 屏幕完全一致, 同样可以参考表格接线
